# Логотипы брендов

Загрузите сюда оригинальные PNG-файлы без повторного сжатия и без изменения размеров.

Названия файлов (точно в нижнем регистре):

- danfoss.png
- ridan.png
- grundfos.png
- wilo.png
- siemens.png
- fancy.png (пока не предоставлен)
- broen.png
- grohe.png
- ekf.png
- buderus.png
- k-flex.png

Лендинг автоматически использует файлы с этими именами. Пока изображение отсутствует, вместо него выводится название бренда. Для логотипов используются исходные пропорции и object-fit:contain без принудительного увеличения.
